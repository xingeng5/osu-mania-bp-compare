# mania BP 对比器

osu!mania 双人 BP（top plays）对比工具：在同一键数与平台口径下并排看两个人的图池，标出 pp差值、补分增益，还能勾选多张图算「补上这些成绩能涨多少 pp」。

单文件 exe，双击即用，不需要装 Node、不需要装谱面。前端源码在本目录；分发用的 7 MB 单文件 exe 由 `go\` 子目录编译产出（Go 把这份 `dist/` 嵌进二进制）。

## 怎么用

1. **双击 `mania-bp-compare.exe`** —— 会自动打开浏览器（默认 `http://127.0.0.1:7788`）
2. **首次启动**会跳到设置页，填一串 osu! OAuth 凭据：
   - 打开 <https://osu.ppy.sh/home/account/edit>，拉到页面底部 **OAuth** 区块
   - 点 **New OAuth Application**：Name 随便填，Redirect URL 填 `http://localhost:7788/callback`（本程序用不到，但表单必填）
   - 创建后把 **Client ID** 和 **Client Secret** 填进设置页，点「保存并开始」——会当场校验，填错会直接告诉你
3. **输入两个玩家**（用户名 / 数字 ID / `osu.ppy.sh/users/...` 链接都行），选键数，开始对比

凭据只需要填这一次，之后双击就用。想换人重填：访问 `http://127.0.0.1:7788/setup`。

## 界面上有什么

| 区域 | 作用 |
|---|---|
| 键数选择 | `4K (A:78 / B:65)` 这样显示双方在该键数下各有多少条 BP；1K–3K 不参与 |
| 平台筛选 | 全部 / 相同平台 / 仅 STB / 仅 LZR；切换后会提示隐藏了多少条跨平台对比 |
| 并排 | 双方同一个名次并排（A 的第 1 名对 B 的第 1 名），只用来对照位置，不表示水平差 |
| 同图 | 双方打过的图合并列表：只有一方有的也列出来，另一侧灰显谱面、pp差值 按 0pp 计 |
| 仅A有 / 仅B有 | 差集。仅 B 有 = 对方有而你没有的图，适合当「上分候选」看 |
| pp差值与增益 | pp差值是同图水平差；增益是「把这张图的成绩给对面，加权总 pp 会涨多少」 |
| 多选批量 | 勾若干行，工具条会算「若A打出相同成绩 / 若B打出相同成绩」各涨多少 pp（一次性重算，不是逐条相加） |
| 筛选条 | rate mod（NM/DT/HT）、星数区间、年份、`\|pp差值\| ≥` |
| 收起设置 | 在「仅B有」右边，收起后只剩一行口径摘要，把屏幕全留给表格 |
| 界面语言 | 右上角「中文 / English」，选择存在浏览器本地，下次打开沿用 |

## 数据口径

- 只读官方 API v2 的**公开数据**，BP 取榜单前 100 条
- 键数按谱面的 `cs` 判定，4K–10K+，1K–3K 直接忽略
- rate mod 只看 DT（含 NC）/ HT（含 DC）：DT 筛的是「带加速的成绩」，HD、MR、IN 之类的修饰 mod 只展示、不参与筛选
- 平台（stable / lazer）由成绩的 `type` 判定：`score_best_mania` = stable，`solo_score` = lazer
- 同图对比分三档：**A** 同图 + 同 rate mod + 同平台（可直接比）；**B** 有一项不同（显示但不计入）；**C** 不同图或一方没有成绩（只看差距）
- **不做 stable↔lazer 的 pp 换算**（官方没有换算表），也不做 pp 重算
- 「加权总 pp」= 100 条成绩按 0.95 递减权重求和，用来解释增益；它不等于官网主页的总 pp（官网还包含 100 条之外的成绩）

## 安全说明

### 它有哪些权限

OAuth 固定用 `scope=public`，也就是**只能读公开数据**：不能发帖、不能聊天、不能改资料、不能看私信。代码里写死在 `server/upstream.ts`，界面无法改。

- 只监听 `127.0.0.1`，局域网和公网都连不上
- 只接受 `127.0.0.1` / `localhost` / `[::1]` 的 `Host` 头，其余一律 403——这条挡的是 DNS rebinding（否则任意网页都能把自己的域名解析到 127.0.0.1 来读你的本地接口）
- 只对外请求 `osu.ppy.sh`（API）与 `assets.ppy.sh`（谱面封面），代理路径固定拼在 `/api/v2` 后面，拼不出别的主机
- 不碰游戏：没有 replay、不读内存、不自动打歌、不上传谱面
- 不采集数据：没有遥测，没有上报；浏览器本地只存最近查过的玩家名与筛选条件

### 你的凭据存在哪

| 项 | 位置 |
|---|---|
| 凭据文件 | **本程序所在目录**的 `mania-bp-compare.config.json`（该目录不可写时改用 `%LOCALAPPDATA%\mania-bp-compare\`） |
| token | 内存，退出即消失 |

程序**不缓存任何查询结果**：每次点「对比」都重新向 osu! 请求，所以你看到的一定是最新的 BP。全程序只留一个 24 小时的 access token（凭据换来的，不落盘），避免每次请求都重新认证。

文件里是**明文**的 Client ID / Client Secret——这是唯一的实质风险：同机的其他程序、其他 Windows 账户、以及会自动同步这个文件夹的网盘（OneDrive / Dropbox 等）都能读到它。所以：

- 别把这个文件夹放进同步盘
- 共享电脑上用完之后删掉那个 json（便携版没有「不保存」开关，填过一次就会落盘）
- 只用自己的凭据，**不要用别人给的、已经配好的 exe**——里面的 secret 是对方的，他随时能撤销，你的用量也会记在他名下

### 凭据泄露了怎么办

去 <https://osu.ppy.sh/home/account/edit> 的 OAuth 区块，把那个应用**删掉重建**（页面上有重置 secret 的选项就用它，没有就删了重建），拿到新的 ID / Secret 重新填。旧 secret 立刻失效。只改应用名字没有用——名字不影响密钥有效性。

### 不会被拿去做什么

- **拿不到别人的账号**：每个人的 exe 只跑自己的 secret，程序里没有任何上传凭据的代码路径
- **不能刷分或作弊**：没有写权限，也不接触游戏进程
- **不能批量抓取**：界面没有遍历用户或导出全站的功能，一次「对比」固定只发 4 个请求（两人各一个用户信息 + 一个 BP 列表），不缓存、不预取、不轮询。真要写脚本绕过界面高频抓取，属于 osu ToS 禁止的 "Harvesting mass score/user/beatmap data"，而且用的是他自己的凭据，后果由他自己承担

### 下载别人给的 exe 时

exe 未签名，SmartScreen 会提示「未知发布者」。想确认没被改过，就用本仓库 `pnpm build` + `go\build.bat` 自己构建，或者核对发布页给出的 SHA-256：

```powershell
Get-FileHash .\mania-bp-compare.exe -Algorithm SHA256
```

## 目录与卸载

便携版只会产生两个文件，都在它所在的文件夹里：

- `mania-bp-compare.exe`
- `mania-bp-compare.config.json`（填了凭据才会有）

不写注册表、不装服务、不加开机启动。**卸载 = 删掉这两个文件**。

## 常见问题

- **端口被占**：`mania-bp-compare.exe --port=7900` 指定起始端口（被占会自动往后顺延）
- **不想自动开浏览器**：加 `--no-open`
- **换电脑 / 换目录**：整个文件夹拷走即可；凭据是跟着文件走的，不需要重填
- **凭据填错了想重填**：删掉 `mania-bp-compare.config.json`，重启后会进设置页；或直接开 `http://127.0.0.1:7788/setup`
- **想让别人零安装**：那得有人托管服务端（Cloudflare Worker + 静态托管），本项目没有做这条路线

## 维护者：改完之后怎么出包

```powershell
# 本目录：改前端，出 dist/
pnpm install
pnpm build

# go\：把 ..\dist 嵌进 exe
cd go
build.bat
```

`build.bat` 会先清空 `web\` 再同步新的 `dist\`（避免哈希文件名的旧资源堆着），然后编译 `dist\mania-bp-compare.exe`。
